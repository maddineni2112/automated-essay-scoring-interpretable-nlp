# Automated Essay Scoring with Interpretable NLP Features

**Timeline:** December 2025  
**Category:** Main project

This project evaluates interpretable NLP features for automated essay scoring. It compares linear and ensemble regressors/classifiers, performs statistical feature analysis, and evaluates agreement using quadratic weighted kappa alongside correlation and significance tests.

## Stack

Python, Pandas, NumPy, NLTK, scikit-learn, XGBoost, Random Forest, Gradient Boosting, Linear SVM, QWK, Welch t-test, ANOVA, Pearson correlation, and Google Colab.

## Repository contents

- `src/Automated_Essay_Scoring.ipynb` — notebook workflow.
- `reports/` — project report and results documentation.
- `data/README.md` — provenance and excluded-data instructions.
